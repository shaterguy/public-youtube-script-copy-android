# 유튜브 스크립트 복사

유튜브 앱 또는 모바일 브라우저의 공유 메뉴에서 이 앱을 선택하면, Defuddle와 Gemini 3.5 Flash-Lite를 경쟁시켜 전체 스크립트를 만든 뒤 클립보드에 복사하는 개인용 Android 앱입니다.

1.3.0부터 전사는 Foreground Service에서 계속되므로 사용자는 처리 중 다른 앱을 자유롭게 사용할 수 있습니다. 진행 상황은 조용한 상시 알림으로 표시하고, 완료되면 소리 또는 진동이 가능한 별도 알림에서 **확인** 또는 **앱 공유**를 선택합니다.

## 1.3.6 주요 변경

- 이미 **사용할 때마다 선택**을 저장한 경우 완료 알림의 **앱 공유** 한 번으로 Android 공유창을 즉시 표시합니다.
- 공유 방식을 다시 확인하는 전사 앱 화면과 추가 **공유 앱 선택** 버튼 단계를 제거했습니다.
- 최초로 공유 방식을 설정하지 않은 상태에서만 **선택한 앱을 기억** 또는 **사용할 때마다 선택** 화면을 표시합니다.
- 기존 v1.3.5에서 저장한 `launch_mode=ALWAYS_ASK` 값을 자동으로 인식하므로 설정을 다시 할 필요가 없습니다.
- 클립보드 포커스를 확보하는 중계 Activity는 투명하게 표시해 공유창 전에 전사 앱 화면이 노출되지 않도록 했습니다.
- 패키지명과 정식 서명 인증서를 이전 버전과 동일하게 유지하고 versionCode를 13으로 올려 v1.3.5 위에 업데이트할 수 있습니다.

## 1.3.5 주요 변경

- 완료 알림에서 **앱 공유**를 누른 직후 Activity의 `onCreate()` 단계에서 클립보드를 읽던 동작을 제거했습니다.
- Android가 앱 창에 입력 포커스를 부여한 뒤 `onWindowFocusChanged(true)`에서 클립보드를 읽습니다.
- 삼성 One UI 등에서 창 포커스 전환이 지연되는 경우를 위해 120ms 간격으로 최대 3회 재시도합니다.
- 공유 앱 기억, 매번 선택, `ACTION_SEND`＋`text/plain` 전달과 긴 스크립트 폴백은 그대로 유지합니다.
- 패키지명과 정식 서명 인증서를 이전 버전과 동일하게 유지하고 versionCode를 12로 올려 v1.3.4 위에 업데이트할 수 있습니다.

## 1.3.4 주요 변경

- 완료 알림은 기존처럼 **확인**과 **앱 공유** 두 버튼만 유지합니다.
- **앱 공유**는 선택 앱의 일반 실행 화면을 여는 대신 전체 스크립트를 `ACTION_SEND`＋`text/plain`으로 전달합니다.
- **선택한 앱을 기억** 모드에서는 저장한 패키지로 바로 공유하고, 설정에서 다른 공유 앱으로 변경할 수 있습니다.
- **사용할 때마다 선택** 모드에서는 매번 Android 공유창에서 대상 앱을 선택합니다.
- 공유 대상 목록은 일반 실행 가능 앱이 아니라 실제 `text/plain` 공유 수신 앱만 표시합니다.
- 스크립트가 Android Intent 전송 한도를 초과하면 클립보드 복사본을 유지한 채 직접 붙여넣기 안내를 표시합니다.
- 패키지명과 정식 서명 인증서를 v1.3.3과 동일하게 유지하고 versionCode를 11로 올려 기존 앱 위에 업데이트할 수 있습니다.

## 1.3.3 주요 변경

- 완료 알림의 **앱 열기** 대상은 특정 런처 Activity의 `ComponentName`이 아니라 앱 패키지명으로 저장합니다.
- 기존 버전의 `launch_component` 설정은 업데이트 후 패키지명으로 자동 이전하고 오래된 Activity 값은 제거합니다.
- 앱을 열 때마다 현재 설치 버전의 공식 front-door 런처 Intent를 다시 조회합니다.
- 기존 task를 강제로 재사용하던 `FLAG_ACTIVITY_CLEAR_TOP`과 `FLAG_ACTIVITY_SINGLE_TOP`을 제거해 ChatGPT의 공유·전송용 비정상 화면으로 연결되는 문제를 수정했습니다.
- 패키지명과 정식 서명 인증서를 v1.3.2와 동일하게 유지하고 versionCode를 10으로 올려 기존 앱 위에 업데이트할 수 있습니다.

## 1.3.2 주요 변경

- Gemini 전사 모델을 `gemini-3.5-flash-lite`로 고정했습니다.
- 모델 선택 옵션은 제공하지 않으며 Gemini 전사가 필요한 모든 요청에 동일한 모델을 사용합니다.
- 기존 Defuddle 2초 지연 경쟁, Gemini 최대 4회 이어받기, 영상 길이 기반 완료 판정과 백그라운드 알림 흐름은 유지합니다.
- 패키지명과 정식 서명 인증서를 이전 정식 버전과 동일하게 유지해 기존 앱 위에 업데이트 설치할 수 있습니다.

## 1.3.0 주요 변경

- APK와 `BuildConfig`에서 Gemini API 키를 완전히 제거했습니다.
- 최초 공유 시 API 키를 직접 입력받고 Android Keystore의 비반출 AES 키로 암호화해 앱 전용 로컬 저장소에만 저장합니다.
- Android 13 이상에서는 최초 설정 중 알림 권한을 요청합니다.
- 공유 직후 시작 Toast를 한 번만 표시하고 공유 수신 Activity를 즉시 종료합니다.
- 기존 Defuddle 2초 지연 경쟁, Gemini 최대 4회 이어받기, 영상 길이 기반 완료 판정을 Foreground Service에서 그대로 수행합니다.
- 진행 알림은 5초 간격으로 경과시간과 Gemini 회차를 갱신하며 **취소** 버튼을 제공합니다.
- 완료 시 전체 스크립트를 먼저 클립보드에 복사한 뒤 진행 알림을 제거하고 완료 알림을 표시합니다.
- 완료 알림의 **확인**은 알림만 닫고, **앱 공유**는 저장한 앱으로 스크립트를 공유하거나 대상 앱을 선택합니다.
- 앱 선택 방식은 **선택한 앱을 기억** 또는 **사용할 때마다 선택** 중 하나입니다.
- 홈 화면의 설정 앱에서 API 키 교체·삭제와 공유 앱 선택 방식을 변경할 수 있습니다.

## 최초 사용

1. `YouTubeScriptCopy-1.3.6.apk`를 설치합니다.
2. 유튜브 앱 또는 브라우저에서 영상을 공유합니다.
3. 공유 대상에서 **유튜브 스크립트 복사**를 선택합니다.
4. 최초 1회 Gemini API 키를 입력합니다.
5. Android 13 이상에서는 알림 권한을 허용합니다.
6. `스크립트 추출을 시작했습니다. 진행 상황은 알림창에서 확인할 수 있습니다.` Toast 후 원래 화면으로 돌아갑니다.
7. 알림창에서 진행 상황을 확인하거나 필요하면 **취소**를 누릅니다.
8. 완료 알림에서 **확인** 또는 **앱 공유**를 선택합니다.
9. 최초 **앱 공유**에서는 공유 앱을 기억할지 매번 선택할지 정합니다.

알림 권한을 거부하면 Foreground Service 알림과 완료 버튼을 정상적으로 사용할 수 없으므로 전사를 시작하지 않습니다. 설정 앱의 **알림 권한 설정 열기**에서 다시 허용할 수 있습니다.

## API 키 보관

Gemini API 키는 소스, Git 기록, APK, 환경 변수 또는 빌드 설정에 포함하지 않습니다.

- 최초 입력값은 앞뒤 공백과 빈 값·예제 placeholder 여부를 검사합니다.
- Android Keystore에 AES/GCM 키를 만들고 키 원문은 기기 밖으로 내보내지 않습니다.
- API 키 암호문과 IV만 앱 전용 `SharedPreferences`에 저장합니다.
- Keystore 복호화가 실패하거나 저장 데이터가 손상되면 암호문을 삭제하고 다시 입력받습니다.
- 설정 앱에서 새 키를 입력하면 기존 값을 교체하고, **저장된 API 키 삭제**를 누르면 암호문과 Keystore 항목을 제거합니다.
- 실제 Gemini 인증 오류는 완료 채널의 실패 알림으로 표시하며, 알림을 누르면 설정 화면을 열 수 있습니다.

기기 자체가 루팅됐거나 앱 프로세스가 침해된 상황까지 API 키를 완전히 보호할 수는 없지만, 모든 사용자에게 같은 키가 들어 있는 APK를 배포하는 기존 방식과 달리 각 사용자의 키가 APK에 존재하지 않습니다.

## 완료 알림

### 확인

- 완료 알림을 제거합니다.
- 다른 앱을 실행하지 않습니다.
- 이미 복사된 스크립트는 클립보드에 유지됩니다.

### 앱 공유

- 스크립트를 Android 표준 `ACTION_SEND`와 `text/plain` 형식으로 대상 앱에 전달합니다.
- **선택한 앱을 기억** 모드에서는 선택 앱의 패키지명만 저장하고 해당 앱으로 바로 공유합니다.
- 설정 앱의 **기본 앱 및 선택 방식 변경**에서 기억된 공유 앱을 다른 앱으로 바꿀 수 있습니다.
- **사용할 때마다 선택** 모드를 이미 저장했다면 전사 앱 설정 화면을 거치지 않고 Android 공유창을 즉시 표시합니다.
- 공유 방식을 아직 한 번도 저장하지 않은 경우에만 최초 방식 선택 화면을 표시합니다.
- 저장된 앱이 삭제됐거나 텍스트 공유를 더 이상 지원하지 않으면 저장값을 지우고 공유 앱 선택 화면으로 복구합니다.
- Android 11 이상 패키지 가시성에 맞춰 `ACTION_SEND`＋`text/plain` 쿼리만 선언하며 `QUERY_ALL_PACKAGES` 권한은 사용하지 않습니다.
- 공유할 원문은 완료 시 클립보드에 저장된 전체 스크립트를 사용합니다.
- Activity 창이 입력 포커스를 얻은 뒤 클립보드를 읽으며, 포커스 전환이 늦으면 짧게 재시도합니다.
- Intent 크기 제한으로 자동 전달할 수 없는 경우 클립보드에서 직접 붙여넣도록 안내합니다.

## 처리 흐름

1. 공유문에서 `watch`, `youtu.be`, `shorts`, `live` 형식의 11자 영상 ID를 찾습니다.
2. 공유 Activity가 API 키와 알림 권한을 확인한 뒤 Foreground Service를 시작하고 즉시 종료합니다.
3. 서비스가 진행 알림을 먼저 표시한 뒤 유튜브 제목·총 길이 조회와 Defuddle Transcript 요청을 병렬 시작합니다.
4. Defuddle가 2초 안에 유효한 전체 스크립트를 반환하면 이를 사용하고 Gemini는 시작하지 않습니다.
5. Defuddle가 먼저 실패하거나 2초 안에 끝나지 않으면 Gemini 3.5 Flash-Lite 전사를 함께 시작합니다.
6. 먼저 유효한 전체 스크립트를 완성한 결과를 원자적으로 채택하고 패배 요청을 취소합니다.
7. Gemini 완료 마커가 있어도 누적 마지막 타임스탬프가 실제 영상 끝에 충분히 가까운지 검증합니다.
8. 마지막 타임스탬프가 영상 끝에서 `최소 30초`, `영상 길이의 3%`, `최대 90초` 허용 범위 안이면 완료하고, 아니면 최대 4회까지 이어서 전사합니다.
9. 정확한 중복과 이전 내용을 새 타임스탬프로 반복한 연속 중복 구간을 제거합니다.
10. 메타데이터와 승자 스크립트가 모두 준비되면 클립보드에 정확히 한 번 기록합니다.
11. Foreground Service와 진행 알림을 종료하고 별도 완료 알림을 표시합니다.

## 클립보드 형식

```text
영상 제목: Example title
영상 주소: https://youtube.com/watch?v=VIDEO_ID
영상 길이: 12:34

[전체 스크립트]
[00:00:00] 화자 1: ...
...
```

Defuddle 페이지 메타데이터와 Gemini 이어받기 제어 표시는 제거하지만 전사 본문은 요약하거나 자르지 않습니다.

## 알림 채널

- **스크립트 추출 진행**: 중요도 낮음, 소리 없음, 진동 없음, 같은 알림 ID로 약 5초마다 갱신
- **스크립트 추출 완료**: 중요도 높음, 팝업 기본 활성화, 사용자 채널 설정에 따른 소리·진동, 사용자가 제거 가능

Android 15 이상에서 `dataSync` Foreground Service는 24시간 동안 누적 6시간 제한을 받습니다. 서비스는 시스템 `onTimeout()` 콜백을 처리해 작업을 중단하고 실패 알림을 남깁니다.

## 권한과 개인정보

사용 권한:

- `INTERNET`
- `FOREGROUND_SERVICE`
- `FOREGROUND_SERVICE_DATA_SYNC`
- `POST_NOTIFICATIONS` — Android 13 이상 런타임 요청

공유된 공개 영상 주소는 다음 서비스에 전달될 수 있습니다.

- 유튜브: 제목과 총 길이 확인
- Defuddle: 기존 공개 자막 추출
- Google Gemini API: Defuddle가 2초 안에 끝나지 않거나 먼저 실패했을 때 영상 전사

앱은 클립보드에 쓰고, 완료 후 사용자가 **앱 공유**를 누른 경우에만 앱 창이 입력 포커스를 얻은 뒤 해당 클립보드 텍스트를 읽어 선택 앱으로 전달합니다. 저장소 권한과 접근성 권한은 요청하지 않습니다.

## 실패 처리

- 유튜브 주소 없음: `유튜브 영상 링크를 찾을 수 없습니다`
- API 키 없음·복호화 실패·인증 오류: `Gemini API 키를 확인해 주세요`
- 무료 한도 초과: `Gemini 무료 사용 한도를 확인해 주세요`
- 비공개·접근 제한 영상: `공개 영상을 전사할 수 없습니다`
- 자동 이어받기 후에도 미완료: `전체 스크립트를 끝까지 만들지 못했습니다`
- 요청 시간 초과 또는 Android 15 서비스 시간 제한: `스크립트 요청 시간이 초과되었습니다`
- 네트워크 오류: `네트워크 연결을 확인해 주세요`
- 기억된 공유 앱 없음·삭제·미지원: 공유 앱 선택 화면으로 복구
- Intent 크기 초과: 클립보드 직접 붙여넣기 안내

실패 시 클립보드에 부분 결과를 쓰지 않습니다. 백그라운드 실패는 완료 채널 알림으로 표시합니다.

- Gradle 8.11.1

```powershell
.\gradlew.bat clean testDebugUnitTest assembleDebug assembleRelease
```

CI는 단위 테스트와 Debug/Release APK 빌드에 더해 앱 소스·Gradle 설정에 빌드 시 Gemini 키 필드가 다시 들어오지 않았는지 검사합니다.

실기기에서 다음 항목은 별도 확인이 필요합니다.

- 최초 API 키 입력과 알림 권한 흐름
- 화면을 끈 상태와 다른 앱 사용 중 Foreground Service 지속
- 진행 알림의 5초 갱신과 취소
- 완료 시 클립보드 전체 내용
- 확인·앱 공유 버튼
- 완료 알림 직후 클립보드 포커스 오류 없이 공유 화면이 열리는지
- **사용할 때마다 선택** 모드에서 전사 앱 화면이나 추가 버튼 없이 공유창이 즉시 열리는지
- ChatGPT·Gemini 등 `text/plain` 수신 앱에 전체 스크립트가 입력되는지
- 기억한 공유 앱으로 다음 실행부터 바로 전달되는지
- 설정에서 공유 앱을 바꾼 뒤 새 앱으로 전달되는지
- 기억한 앱 삭제 후 공유 앱 선택 화면으로 복구되는지
- 긴 스크립트 Intent 실패 시 클립보드 폴백 안내가 표시되는지
- Android 13∼16 알림 권한 및 제조사 배터리 정책 차이
