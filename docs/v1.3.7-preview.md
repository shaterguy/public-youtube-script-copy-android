# v1.3.7 Preview

## 문제

v1.3.6은 완료 알림의 `앱 공유`를 누르면 시스템 공유창을 바로 띄웠지만, 공유 중계 Activity가 앱의 기존 task를 재사용해 공유창 아래에 마지막으로 열었던 전사 앱 설정 화면이 노출될 수 있었습니다.

## 수정

- 알림이 실행하는 `AppSelectionActivity`를 공유 전용 중계 Activity로 분리했습니다.
- 중계 Activity에 `android:taskAffinity=""`, `android:excludeFromRecents="true"`, `android:noHistory="true"`, 투명 테마를 적용했습니다.
- 기존 설정 화면은 `ShareConfigurationActivity`로 분리했습니다.
- `사용할 때마다 선택` 상태에서는 현재 사용 중인 앱 화면 위에 Android 공유창을 바로 표시합니다.
- 최초 미설정 상태와 설정 앱에서의 대상 변경에만 별도 설정 화면을 사용합니다.
- 패키지명과 서명 인증서는 기존 설치본과 동일하며 versionCode 14, versionName 1.3.7입니다.

## 실기기 확인

1. 유튜브 화면에서 전사를 시작합니다.
2. 완료 알림의 `앱 공유`를 누릅니다.
3. 공유창 아래 배경이 전사 앱 설정 화면이 아니라 직전에 사용하던 유튜브 화면인지 확인합니다.
4. ChatGPT를 선택해 전체 스크립트가 새 대화 입력창에 전달되는지 확인합니다.
